Enunciados: Actividades de Vue.js 3

Colección de ejercicios prácticos para consolidar directivas, reactividad y comunicación entre componentes utilizando Composition API (<script setup>).

Bloque 1: Condicionales con v-if, v-else-if y v-else

Ejercicio 1.1: Interruptor de visibilidad de panel

Objetivo: Crear un componente PanelDetalles.vue que gestione la visibilidad de información sensible.

  • Declara una variable reactiva booleana mostrarInfo (inicializada en false).
  • Añade un botón que alterne el valor entre true y false al hacer clic.
  • El texto del botón debe cambiar dinámicamente ("Mostrar detalles" / "Ocultar detalles").
  • Si está activo, muestra una caja con información técnica (servidor, versión, estado). Si está inactivo, muestra un mensaje invitando al usuario a pulsar el botón.

Ejercicio 1.2: Clasificador de calificaciones por tramos

Objetivo: Crear un componente CalificacionExamen.vue para evaluar una nota académica.

  • Añade un campo <input type="number"> vinculado con v-model.number a una variable nota.
  • Mediante v-if, v-else-if y v-else muestra el estado según la puntuación:
    • Menor a 0 o mayor a 10: "Nota no válida".
    • Menor a 5: "Insuficiente / Suspenso".
    • Entre 5 y 8.9: "Aprobado / Notable".
    • 9 o superior: "Sobresaliente".

Bloque 2: Renderizado de Listas con v-for

Ejercicio 2.1: Lista de tareas pendientes con índice

Objetivo: Crear un componente ListaTareas.vue para listar cadenas de texto.

  • Declara un array reactivo con al menos 4 tareas pendientes.
  • Utiliza la directiva v-for="(tarea, index) in tareas" para pintar una lista ordenada con número y nombre de tarea.
  • Controla con v-if que si el array se queda vacío, aparezca un mensaje de felicitación informando que no hay tareas pendientes.

Ejercicio 2.2: Tabla de catálogo de productos

Objetivo: Crear un componente TablaCatalogo.vue para renderizar colecciones de objetos.

  • Declara un array de objetos donde cada elemento tenga id, nombre, categoria y precio.
  • Construye una tabla HTML con cabecera (<thead>) y filas (<tr>) generadas con v-for.
  • Asegúrate de incluir la directiva :key="item.id" en cada fila para garantizar la identidad única de renderizado.

Bloque 3: Manipulación de Arrays Reactivos

Ejercicio 3.1: Añadir y eliminar elementos (Lista de asistencia)

Objetivo: Crear un componente GestorInvitados.vue con operaciones de inserción y borrado.

  • Incluye un campo de entrada de texto y un botón "Añadir".
  • Al pulsar o presionar Enter, valida que no esté en blanco e inserta el nombre en el array (push).
  • Cada elemento de la lista debe contar con un botón "Eliminar" que suprima dicho elemento por su índice (splice).

Ejercicio 3.2: Filtrado y ordenación con computed

Objetivo: Crear un componente FiltradoAlumnos.vue que derive datos sin mutar el array original.

  • Crea un array de alumnos con sus respectivas notas numéricas.
  • Añade un <input> para filtrar la lista en tiempo real por coincidencia en el nombre.
  • Añade un botón para conmutar entre orden por defecto y orden descendente de mayor a menor nota.
  • Implementa la lógica mediante una propiedad calculada (computed).

Bloque 4: Propiedades Computadas con computed()

Ejercicio 4.1: Calculadora de Carrito de Compras

Objetivo: Crear un componente CalculadoraCarrito.vue que calcule totales derivados automáticamente.

  • Declara un array reactivo con varios artículos (nombre, precio unitario y cantidad).
  • Crea propiedades computadas (computed) para obtener:
    • El número total de unidades en la cesta.
    • El importe subtotal (suma de precio * cantidad).
    • El IVA estimado (21% del subtotal).
    • El total general de la compra.
  • Permite modificar la cantidad de cada producto mediante botones dinámicos (+ / -).

Ejercicio 4.2: Evaluador de Fortaleza de Contraseñas

Objetivo: Crear un componente ValidadorPassword.vue para comprobar la robustez de claves.

  • Añade un campo <input type="password"> enlazado a una variable reactiva password.
  • Implementa propiedades computadas para validar requisitos individuales (longitud ≥ 8, al menos una mayúscula, un número y un símbolo especial).
  • Calcula una puntuación acumulada del 0% al 100% y un nivel descriptivo (Muy débil, Débil, Media, Fuerte).
  • Refleja el resultado dinámicamente en una barra de progreso.

Bloque 5: Observadores con watch()

Ejercicio 5.1: Guardado Automático en LocalStorage

Objetivo: Crear un componente BlocNotasAutoGuardado.vue que sincronice su estado con almacenamiento local.

  • Añade un <textarea> para que el usuario escriba notas de texto libre.
  • Utiliza watch() sobre la variable de la nota para detectar escrituras y persistir el contenido en localStorage (con un breve retardo o feedback de estado).
  • Al montar el componente (onMounted), recupera el contenido anterior si existiese en el navegador.
  • Incluye un botón para borrar y limpiar el almacenamiento.

Ejercicio 5.2: Búsqueda Reactiva con Simulación de API y Historial

Objetivo: Crear un componente BuscadorUsuarios.vue con efectos secundarios asíncronos.

  • Añade un <input> de búsqueda conectado a una variable reactiva.
  • Observa la búsqueda con watch() accediendo a (nuevoValor, viejoValor).
  • Guarda un registro de historial con las transiciones de búsqueda detectadas.
  • Simula una consulta de red asíncrona (con setTimeout y un indicador de carga / spinner) filtrando una lista de usuarios.

Bloque 6: Paso de Datos con defineProps

Ejercicio 6.1: Componente Tarjeta de Usuario (UserCard)

Objetivo: Crear un componente hijo reutilizable TarjetaUsuario.vue y consumirlo desde App.vue.

  • El componente hijo debe definir las props:
    • nombre (String, obligatorio).
    • rol (String, obligatorio).
    • activo (Boolean, valor por defecto: true).
  • Aplica estilos condicionales (opacidad o color de insignia) si la cuenta del usuario no está activa.
  • En App.vue, instancia al menos 3 tarjetas pasando distintos datos por props.

Ejercicio 6.2: Componente Alerta Reutilizable (CustomAlert)

Objetivo: Crear un componente AlertaMensaje.vue con validación de propiedades.

  • Define una prop mensaje (String obligatorio) y una prop tipo (con valor por defecto 'info').
  • Añade una función validadora en la prop tipo para permitir únicamente los valores 'info', 'exito' o 'peligro'.
  • Aplica clases o estilos acordes al tipo de alerta y utilízalo en App.vue mostrando varios mensajes.

Bloque 7: Comunicación de Hijo a Padre con defineEmits

Ejercicio 7.1: Contador Modular con Emisión de Eventos

Objetivo: Desacoplar los controles visuales del estado con defineEmits.

  • Crea el componente hijo BotonesContador.vue con dos botones ("+1" y "-1").
  • Al hacer clic en cada botón, emite los eventos personalizados incrementar o decrementar (sin manipular ningún valor interno).
  • En el componente padre App.vue, almacena la variable reactiva cuenta y escucha ambos eventos para modificarla.

Ejercicio 7.2: Formulario hijo que emite un objeto al componente padre

Objetivo: Enviar datos complejos desde un formulario hijo hacia la lista del padre.

  • Crea el componente FormularioProducto.vue con campos para nombre y precio.
  • Al enviar el formulario (@submit.prevent), emite el evento personalizado producto-creado pasando como argumento el objeto con los datos introducidos.
  • En App.vue, escucha @producto-creado y añade el objeto recibido a su lista reactiva de productos.
